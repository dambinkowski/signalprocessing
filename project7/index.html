Project 7: Multilingual Speech Analysis

Offline speech recognition and error analysis across English, Spanish, and Italian datasets.

Report Summary

The report presents a DeepSpeech-based multilingual recognition pipeline with language-specific models and transcript-based evaluation.

  • Creates per-language model instances and processes curated audio/transcription pairs.
  • Applies noise reduction preprocessing (plus additional handling for some Italian files).
  • Runs recognition and evaluates output using WER to compare transcript quality across languages.
