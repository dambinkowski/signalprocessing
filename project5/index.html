Report Summary

The project evaluates which real-time audio descriptors best map to visual controls and motion logic across different music tracks.

  • Energy captures intensity changes and transient peaks.
  • Spectral centroid and slope track timbral movement over time.
  • Zero crossing rate supports pitch/noisiness-driven parameter shifts.
