Project 5: Audio Feature Extraction

Real-time feature extraction using p5.js + Meyda for analysis-driven visual behavior in the browser.

Report Summary

The report evaluates which Meyda features are most useful for controlling visuals from sound. Different tracks are analyzed to map feature dynamics to animation behavior.

  • Energy captures loudness shifts and amplitude bursts.
  • Spectral centroid and slope capture timbre and foreground/background tonal movement.
  • Zero crossing rate reflects pitch/noisiness trends and supports smooth parameter modulation.
