Project 2: Audio File Encoding

Encoding and decoding WAV data using custom K-bit quantization to study compression and quality trade-offs.

Report Summary

The report documents a two-part audio pipeline: encoding and decoding. The implementation reads WAV bytes, maps sample values into a reduced K-bit representation, and stores compact binary output.

  • Encoding stage converts sample integers into K-bit codes and packs them into bytes for storage efficiency.
  • Decoding stage reconstructs sample values from the encoded bitstream to generate a playable output file.
  • The method highlights the relationship between bit depth, audible quality, and file size reduction.
