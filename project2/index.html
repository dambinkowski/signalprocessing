Audio File Encoding

Custom K-bit audio quantization pipeline for encoding and decoding WAV files while analyzing the trade-off between compression efficiency and output quality.

Audio Processing Quantization Compression Analysis

Report Summary

The workflow reads WAV samples, converts amplitude values to compact K-bit codes, then reconstructs the signal to evaluate perceptual impact and storage gain.

  • Encoding maps raw samples into lower-bit representations and packs them efficiently.
  • Decoding restores playable sample values from the compact binary stream.
  • Experiments show how smaller K reduces file size but can increase audible distortion.
