Interactive Audio Visualizer

A p5.js web app that reacts to sound playback with interactive visual patterns and logarithmic volume behavior for perceptual smoothness.

Web Audio p5.js + p5.sound Interactive Visuals

Report Summary

The project bridges audio editing fundamentals and live browser graphics by combining prepared audio assets with real-time signal-driven rendering.

  • Covers recording, cleaning, effects, and export workflow in Audacity.
  • Maps signal behavior to visual parameters in a p5.js rendering loop.
  • Applies logarithmic volume control to better match human loudness perception.
