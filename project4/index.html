Project 4: Interactive Audio Visualizer

A p5.js audio application with interactive playback and visual response to signal behavior.

Report Summary

The report starts with Audacity workflow fundamentals and then transitions to the web implementation. It covers recording, editing, applying effects, and exporting audio before integrating those concepts into an interactive browser app.

  • Explains practical audio preparation steps: cleanup, effect processing, and export settings.
  • Applies signal interpretation to a p5.js visualization pipeline.
  • Uses logarithmic volume behavior to better match human loudness perception.
