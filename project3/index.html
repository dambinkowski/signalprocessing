Project 3: Video Analysis and Processing

Automated video quality analysis and correction using FFmpeg/FFprobe-based processing logic.

Report Summary

The report describes environment setup and an application pipeline that inspects video properties and applies corrections when values do not match target constraints.

  • FFmpeg and FFprobe were configured through Homebrew for reliable command-line access on macOS.
  • The analysis function reads technical parameters frame/field metadata and compares them to required values.
  • When mismatches are detected, processing commands generate a corrected output file and document the applied adjustments.
